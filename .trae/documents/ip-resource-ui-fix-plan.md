# IP资源管理界面修复计划

## 问题分析

### 问题1：IP资源管理界面编辑功能无法打开
- 用户点击编辑按钮后无法查看爬取到的IP内容
- 可能原因：API路径编码问题、前端事件绑定问题、资源读取接口问题

### 问题2：自动获取资源的国家列表展示不佳
- 当前国家列表太小，内容太少，展示不美观
- 需要改进多选列表的样式和交互体验

### 问题3：各资源获取板块的IP资源选择下拉列表不显示新爬取内容
- TCP的IP资源选择下拉列表只显示固定文件，不显示新爬取的内容
- Memcached/DNS/NTP等板块展示方式不一致，需要统一优化

## 修复方案

### 1. 修复编辑功能
- 检查并修复 `attack_resource_api.py` 中的资源读取接口
- 确保路径编码正确处理
- 修复前端 `script.js` 中的编辑事件绑定

### 2. 改进国家列表展示
- 扩大多选列表的尺寸
- 添加搜索/过滤功能
- 优化样式，使其更清晰易读

### 3. 统一IP资源选择下拉列表
- 修改TCP资源加载接口，使其从IPResourceManager获取资源
- 添加资源刷新机制
- 优化下拉列表的展示，显示文件来源、国家、协议等信息

## 文件修改清单

### 后端修改
1. `attack_resources/shared/attack_resource_api.py` - 修复资源读取接口
2. `attack_resources/tcp/code/tcp_censor_scan/resources.py` - 确保资源列表正确获取

### 前端修改
3. `templates/index.html` - 改进国家列表和下拉列表样式
4. `static/script.js` - 修复编辑功能、改进国家列表、统一资源选择
5. `static/style.css` - 添加国家列表和资源选择的样式

## 实施步骤

### 步骤1：修复编辑功能
- 检查API接口是否正确处理路径参数
- 确保前端传递路径时编码正确
- 添加错误处理和日志

### 步骤2：改进国家列表展示
- 扩大多选select的size属性
- 添加搜索框过滤国家
- 添加全选/取消全选按钮
- 优化CSS样式

### 步骤3：统一资源选择下拉列表
- 修改TCP资源加载逻辑，使用IPResourceManager
- 在下拉列表中显示文件类型标识（手动/自动）
- 添加刷新按钮，支持实时获取新爬取的资源

## 风险处理

- 修改API接口可能影响现有功能，需进行测试
- 国家列表数据较多，需考虑性能优化
- 资源列表更新需要同步到所有协议板块

## 验证方法

1. 点击资源管理界面的编辑按钮，确认能正常打开并显示文件内容
2. 在自动获取资源中选择国家，确认列表展示清晰
3. 爬取新资源后，在各协议板块的IP资源下拉列表中能看到新文件
